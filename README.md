**Assembly Simplifier (ASM)**
Simplifying assembly code analysis with Python.

## Features

* Analyze binary files using PyGhidra
* Load and decompile binary containers
* Generate C code from disassembled instructions

## Tech Stack

* Primary Language: Python
* Libraries:
	+ PyGhidra
	+ Ghidra modules (Decompiler, Auto Analysis Manager)

## Getting Started

1. Clone the repository: `git clone https://github.com/your-username/asm.git`
2. Install dependencies: `pip install pyghidra ghidra`
3. Run the main.py script to start analyzing binary files.
